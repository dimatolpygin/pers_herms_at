# Lead Magnets (HTML → PDF)

## Overview

Создание красивых многостраничных PDF-документов для маркетинговых целей:
лид-магниты, гайды, памятки, чек-листы. Вёрстка — чистый HTML/CSS,
конвертация — `wkhtmltopdf` (предустановлен в системе).

## When to Use

- «Сделай лид-магнит на N страниц»
- «Сделай PDF-гайд / памятку / чек-лист»
- «Красивый PDF для раздачи за подписку»
- Любой дизайнерский PDF, где важна вёрстка (цвета, шрифты, карточки, сетки)

**Не используй** для: КП/договоров (.docx → `business-documents`), слайдов (→ `powerpoint`), простых текстовых документов без дизайна.

## Workflow

### 1. Дизайн и структура

- Определи количество страниц и смысловые блоки.
- Подбери цветовую гамму: тёмная/светлая тема, акцентный цвет.
- Для типографики используй Google Fonts (через `@import`) — например, Inter.
- Каждая страница — отдельный `<div class="page">…</div>`.

### 2. Вёрстка HTML

**Критически важно: размеры страниц в пикселях, а не в миллиметрах!**
wkhtmltopdf некорректно интерпретирует `mm` — контент сжимается и занимает
~¾ листа. Правильные размеры для A4 при 96 DPI:

```css
@page {
  size: A4;
  margin: 0;
}

.page {
  width: 794px;    /* A4 width at 96 DPI */
  height: 1123px;  /* A4 height at 96 DPI */
  page-break-after: always;
  overflow: hidden;
  position: relative;
}
.page:last-child { page-break-after: avoid; }
```

**Структура типовой страницы:**
- `.page` — контейнер с фиксированными px-размерами + `position: relative`
- `.page-footer` — колонтитул внизу страницы (`position: absolute; bottom: 20px`)
- Flexbox для распределения контента по высоте (`display: flex; flex-direction: column`)
- `flex: 1` у основного контентного блока, чтобы он растягивался

**Готовый шаблон:** `templates/lead-magnet-base.html` — чистая вёрстка на 3 страницы (обложка, контент, CTA). Скопируй как основу, замени текст и цвета под задачу.

### 3. Конвертация в PDF

```bash
cd /root/lead-magnet && wkhtmltopdf \
  --page-size A4 \
  --enable-local-file-access \
  --no-stop-slow-scripts \
  --javascript-delay 3000 \
  input.html \
  "output.pdf"
```

**Важно:** флаги `--disable-smart-shrinking` и `--print-media-type` **не работают**
на стандартном пакете wkhtmltopdf из apt (0.12.6 — непропатченный Qt).
Они будут проигнорированы с предупреждением. Не добавляй их.

`--javascript-delay 3000` нужен, чтобы успели загрузиться Google Fonts.

### 4. Доставка

Через `MEDIA:<absolute path>` в ответе. Файл клади в `/root/lead-magnet/`.

## Pitfalls

1. **mm вместо px — самая частая проблема.** Никогда не используй `width: 210mm; min-height: 297mm` в CSS. Контент займёт ¾ листа. Только пиксели: 794×1123.

2. **Не используй `--disable-smart-shrinking`** — флаг игнорируется на стандартном wkhtmltopdf 0.12.6. Если контент всё ещё сжимается — проверь, что используешь px, а не mm.

3. **`height: 297mm` не равно `height: 1123px`** в wkhtmltopdf. Расчёт: A4 = 210×297 мм, при 96 DPI → `round(210/25.4*96) = 794px`, `round(297/25.4*96) = 1123px`.

4. **Футер через absolute.** Не используй `margin-top: auto` для футера на странице с `height: 1123px` — позиционируй абсолютно: `position: absolute; bottom: 20px`.

5. **Переполнение контента.** Если текста больше, чем влезает в 1123px — он будет обрезан (`overflow: hidden`). Либо уменьшай шрифты/отступы, либо разбивай на больше страниц.

6. **Google Fonts.** Без `--javascript-delay` шрифт может не успеть загрузиться и PDF отрендерится с fallback-шрифтом.
