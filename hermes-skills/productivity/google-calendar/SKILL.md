# Google Calendar — встречи и события

## Overview

Работа с календарём клиента: посмотреть, что запланировано, завести встречу,
перенести её и удалить. Доступ идёт через **сервисный аккаунт Google** — он не
истекает и не требует, чтобы человек проходил вход в браузере.

> **Почему не штатный `google-workspace`.** Тот навык умеет только читать,
> создавать и удалять — **правки событий в нём нет**, а авторизация только
> OAuth (токен надо периодически обновлять руками). И главное: его файлы
> лежат в каталоге установки hermes и **переписываются при обновлении** — правка
> там не выживет. Поэтому календарь ведём этим навыком.

## Главное правило: подтверждение перед записью

**Ничего не создавай, не переноси и не удаляй молча.** Сначала скажи человеку,
что именно собираешься сделать — название, дата, время, календарь — и дождись
согласия. Читать (`list`, `calendars`) можно без спроса.

Плохо: _«Готово, встреча создана»_ (человек не просил именно этого времени).
Хорошо: _«Поставлю „Созвон с Ирой“ в четверг 7 августа, 15:00–16:00. Ставлю?»_

## Как пользоваться

Все команды печатают JSON. Пересказывай человеку результат словами, а не JSON.

```bash
GCAL="python scripts/gcal.py"

# какие календари вообще доступны (нужно один раз, чтобы узнать ID)
$GCAL calendars

# что запланировано (по умолчанию — ближайшие 7 дней)
$GCAL list
$GCAL list --from 2026-08-10 --to 2026-08-17

# создать
$GCAL create --summary "Созвон с Ирой" --start 2026-08-07T15:00 --end 2026-08-07T16:00
$GCAL create --summary "Мастер-класс" --start 2026-08-09T12:00 --end 2026-08-09T15:00 --location "Малая Бронная 12"

# перенести/переименовать — меняются ТОЛЬКО переданные поля
$GCAL update EVENT_ID --start 2026-08-07T17:00 --end 2026-08-07T18:00
$GCAL update EVENT_ID --summary "Созвон с Ирой (перенесён)"

# удалить
$GCAL delete EVENT_ID
```

### Как переносить встречу

`update` требует `EVENT_ID`, а человек его не знает и знать не должен. Порядок:

1. `list` за нужный период;
2. найди событие по названию/времени, возьми его `id`;
3. если подходящих несколько — **спроси, какое именно**, не угадывай;
4. покажи, что собираешься изменить, и после согласия вызови `update`.

При переносе передавай **и `--start`, и `--end`** — иначе встреча растянется или
схлопнется. Если человек говорит «сдвинь на час», посчитай оба конца сам.

## Время

- Время без таймзоны считается **московским** — писать смещение не нужно.
- Форматы: `2026-08-07` (дата), `2026-08-07T15:00`, `2026-08-07T15:00+03:00`.
- «Завтра», «в четверг», «через неделю» переводи в конкретную дату сам,
  предварительно узнав сегодняшнее число (`date`) — не считай в уме от балды.

## Настройка

| Переменная | Что это |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_FILE` | путь к JSON сервисного аккаунта (`/root/.hermes/google_service_account.json`) |
| `GOOGLE_CALENDAR_ID` | календарь по умолчанию; если не задан — `primary` |

**У сервисного аккаунта нет своего `primary`.** Он видит только те календари,
которые ему явно расшарили. Поэтому `GOOGLE_CALENDAR_ID` должен указывать на
календарь клиента, а доступ выдаётся с правом **«Внесение изменений в
мероприятия»** — прав на просмотр для создания и правки не хватит.

## Если что-то не работает

| Ответ скрипта | Что это значит |
|---|---|
| `Google Calendar API выключен в проекте` | владелец Google-проекта не включил Calendar API в консоли |
| `нет доступа к календарю …` | календарь не расшарен на сервисный аккаунт (или дали только «Просмотр») |
| `calendars` вернул пусто | ни один календарь не расшарен — это не поломка скрипта |
| `не найдено: событие или календарь` | `EVENT_ID` устарел — переспроси через `list` |
| `не задан GOOGLE_SERVICE_ACCOUNT_FILE` | переменной нет в `.env` |

Ошибку **пересказывай честно и своими словами** — не выдумывай событий, которых
не видел, и не сообщай об успехе, если скрипт вернул `"ok": false`.
