# Задачи по расписанию (крон / напоминания)

Заводить и вести задачи по расписанию нужно **встроенным инструментом `cronjob`**
(не через файлы). В назначенное время задача выполняется агентом в чистой сессии,
и результат приходит пользователю в тот же чат.

Это про **личные задачи пользователя** («напомни…», «каждое утро присылай…»).
Служебный автопостинг (`cron/autopost.py`, этап 6) — отдельное, его тут не касаемся.

## Когда применять

«Напомни мне …», «через N минут/часов …», «каждый день/час/неделю …»,
«по расписанию …», а также «покажи мои задачи», «удали/выключи задачу».

## Что выяснить (если не дано)

1. **Что сделать** — задача исполнится сама, без пользователя, поэтому `prompt`
   должен быть **самодостаточным**: пиши всё явно, без «как договорились выше».
   Для простого напоминания это буквально текст: «Напомни: позвонить в банк».
2. **Когда / как часто** — переведи в формат расписания (ниже). Время — **МСК**.
   Если время неоднозначно — уточни.

## Инструмент `cronjob`

Создать задачу:
```
cronjob(action="create", schedule="<расписание>", name="<короткое имя>",
        prompt="<самодостаточная инструкция>")
```
Посмотреть задачи: `cronjob(action="list")`
Удалить: `cronjob(action="remove", job_id="<id>")`

Результат по умолчанию доставляется в чат, откуда пришла просьба.

## Формат расписания (`schedule`)

- `30m`, `2h` — **разово** через 30 минут / 2 часа.
- `2026-07-02T18:00` — **разово** в конкретную дату-время (МСК).
- `every 30m`, `every 2h` — **повтор** каждые 30 минут / 2 часа.
- `0 9 * * *` — cron-выражение (5 полей: мин час день месяц день_недели). Примеры:
  - `0 9 * * *` — каждый день в 09:00
  - `0 * * * *` — каждый час
  - `0 10 * * 1` — каждый понедельник в 10:00
  - `0 18 * * 5` — каждую пятницу в 18:00

Разовое напоминание = `30m` / ISO-время; регулярное = `every …` или cron-выражение.

## Примеры

Напомнить через 30 минут:
```
cronjob(action="create", schedule="30m", name="Напоминание: банк",
        prompt="Напомни пользователю: позвонить в банк.")
```

Каждый день в 9:00 присылать погоду:
```
cronjob(action="create", schedule="0 9 * * *", name="Утренняя погода",
        prompt="Составь короткую сводку погоды на сегодня по Москве (поищи актуальные данные) и пришли текстом.")
```

Разово в конкретное время сегодня:
```
cronjob(action="create", schedule="2026-07-02T18:00", name="Созвон",
        prompt="Напомни пользователю про созвон в 18:00.")
```

## Важно

- **Время — МСК** (в конфиге `timezone: Europe/Moscow`). При деплое на сервер
  таймзона должна остаться `Europe/Moscow` (`HERMES_TIMEZONE` или `timezone:` в config).
- `prompt` должен быть выполним без пользователя — никаких «спроси у него».
- Если задача требует свежих данных (погода, курс, новости) — в `prompt` явно скажи
  «поищи актуальное», чтобы сработал веб-поиск, а не выдумка.
- Не плоди слишком частые задачи без нужды (каждая минута = расход токенов).

## Выдача

После создания коротко подтверди: что за задача, когда сработает (человеческим
языком, МСК), разовая или повторяющаяся. Список — `cronjob(action="list")`.

## Verification Checklist

- [ ] `cronjob(action="create", schedule="Nm", …)` — разовое напоминание приходит в срок.
- [ ] cron-выражение / `every …` — повторяющаяся задача срабатывает по расписанию.
- [ ] `cronjob(action="list")` показывает задачи; `remove` удаляет.
- [ ] Время трактуется как МСК; разовая не повторяется, повторяющаяся не исчезает после первого раза.
