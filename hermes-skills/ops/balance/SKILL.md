# Balance — остатки на счетах провайдеров

## Overview

Показывает, сколько осталось на счетах ИИ-сервисов, которыми пользуется агент:
**OpenRouter** (инференс, в долларах), **kie.ai** (генерация картинок, в кредитах)
и **fal.ai**. Нужен, чтобы клиент не заходил в три личных кабинета.

Навык называется `balance`, поэтому в Telegram он же — команда **`/balance`**
(меню бота собирается из встроенных команд плюс навыков).

## Как пользоваться

Запусти helper и покажи пользователю его вывод:

```bash
python scripts/balance.py check
```

Для машинной обработки есть `--json`. Скрипт stdlib-only, зависимостей нет.

Вывод уже отформатирован для человека — **отдавай его как есть**, не пересчитывай
и не переписывай цифры.

## Важно: цифры только из helper

Это данные о деньгах — здесь действует правило достоверности (этап 8) в самом
строгом виде:

- **Никогда не называй остаток по памяти или на глаз.** Только то, что вернул
  helper прямо сейчас. Цифры меняются после каждого запроса к модели.
- Если helper по какому-то провайдеру вернул «не смог узнать» — так и передай,
  вместе с причиной. **Не выдумывай** число и не подставляй прошлое значение.
- Один недоступный провайдер не отменяет остальные — показывай, что есть.

## Ключи

Helper сам читает `.env`, ничего экспортировать не нужно:

| Переменная | Зачем |
|---|---|
| `OPENROUTER_MANAGEMENT_KEY` | остаток OpenRouter в $ |
| `OPENROUTER_API_KEY` | расход за день/неделю/месяц |
| `KIE_AI_API_KEY` | кредиты kie.ai |
| `FAL_ADMIN_KEY` | баланс fal.ai |

Два нюанса, вскрытые на разведке (этап 13) — если увидишь такую ошибку, объясни
её человеку, а не пытайся обойти:

- **OpenRouter**: обычный рантайм-ключ остаток **не отдаёт** (`403 Only management
  keys can fetch credits`). Нужен именно management-ключ.
- **fal.ai**: у ключей два скоупа — `API` и `Admin`. Биллинг требует **Admin**;
  обычный API-ключ даёт `403`. Admin-ключ создаётся на https://fal.ai/dashboard/keys.

`OPENROUTER_MANAGEMENT_KEY` и `FAL_ADMIN_KEY` намеренно **не** проброшены в
песочницу через `terminal.env_passthrough` — helper читает их из `.env` сам.
Не пытайся печатать эти ключи и не выноси их в чат.

## Единицы

- OpenRouter — доллары. Остаток = `total_credits − total_usage`.
- kie.ai — **кредиты**, не доллары. Так и говори: «930 кредитов».
- fal.ai — доллары (валюта приходит из ответа).
