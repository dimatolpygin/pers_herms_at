# Правка своих навыков

Агент может **править существующие** навыки по просьбе пользователя встроенным
инструментом `skill_manage`. Правки применяются к файлам навыков; штатный
write-gate hermes оставляем как есть (это защита от самовольных изменений).

## Область (важно)

- **Здесь**: редактирование уже существующих навыков — менять текст/правила/описание,
  дополнять, убирать лишнее.
- **Создание нового навыка с нуля — не здесь**, а в навыке **`skill-creator`**
  (там интервью, черновик и подтверждение человека перед созданием). `skill_manage(create)`
  на существующее имя всё равно откажет по конфликту.
- Правь только пользовательские навыки проекта (content-studio, postmypost,
  s3-upload, cron-tasks и т.п.). Встроенные/системные навыки hermes не трогай.

## Порядок

1. **Найди и прочитай навык**: `skills_list()` → `skill_view(name="<навык>")`. Убедись,
   что это существующий навык и ты понял его текущее содержимое.
2. **Внеси точечную правку** через `skill_manage`:
   ```
   skill_manage(action="patch", name="<навык>",
                old_string="<что заменить>", new_string="<на что>")
   ```
   - `patch` — для точечной замены фрагмента (предпочтительно).
   - `edit` — если нужно переписать содержимое навыка целиком (передай новый `content`).
3. **Сохрани валидность**: не сломай YAML-фронтматтер (`--- … ---`), поля `name`,
   `description`. После правки перечитай `skill_view`, чтобы убедиться, что навык цел.
4. **Отчитайся**: коротко скажи пользователю, что именно изменил (какой навык, какая
   правка).

## Важно

- Меняешь собственное поведение — будь аккуратен: правь ровно то, о чём просят,
  не переписывай лишнего.
- Если правка большая или рискованная — сначала покажи пользователю, что собираешься
  изменить, и дождись подтверждения.
- Установленная копия навыка (в рабочей папке hermes) — это то, что реально исполняется.
  Правки через `skill_manage` идут именно туда.

## Verification Checklist

- [ ] `skill_view` существующего навыка → виден текущий текст.
- [ ] `skill_manage(action="patch"/"edit")` вносит правку, `success: true`.
- [ ] Повторный `skill_view` показывает изменение; фронтматтер валиден.
- [ ] Просьба «создай навык с нуля» уходит в навык `skill-creator`, а не обрабатывается здесь.
