# Старт сессии (okplan — обязательно)
Прежде чем брать любую задачу в новой сессии:
1. Прочитать `docs/STATUS.md` — текущий этап, активная работа, блокеры.
2. `git tag -l "stage-*"` — машинно-проверяемая правда о закрытых этапах; сверить с таблицей в STATUS.
3. `git log --oneline -10` — что менялось последним.
4. Открыть `docs/07_ROADMAP.md` на текущем этапе — там чекбоксы acceptance-критериев.
Приоритет источников правды: **git-тег > чекбоксы ROADMAP > проза STATUS**. После каждого этапа — мини-отчёт человеку и человеческая верификация перед тегом.
