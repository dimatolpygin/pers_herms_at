## Главная находка: навыки в основном уже написаны

На проде **128 навыков**, из них **71 из поставки** hermes (`.bundled_manifest`) и
**~57 добавлены сверх** — клиентом и Герой, уже после нашего последнего этапа. Среди них есть
почти всё, что перечислено в ТЗ v8: `seo/wordstat-api`, `seo/semantic-core`, `seo/seo-tilda`,
`ops/rus-ip-tax-calc`, `ops/tilda-api`, `productivity/proposal-formatting`,
`writing/professional-text-editing`, `marketing/jobs-to-be-done`, `ai-image-prompts` и другие.

**Практический вывод: блок v8 — это не проект разработки, это проект приёмки и разводки.**
Основная работа — не «написать навыки», а проверить существующие живьём, починить сломанное,
разложить по профилям и заставить Геру делегировать.

**Риск ровно тот же**: эти навыки писал тот же агент, который «забывает делегировать». Ни один
из ~57 не проходил человеческую верификацию. Пока не проверено — считаем, что не работает.

разобрать, а не отмести.

**Что решить**: какая таблица моделей канон. Рекомендация — взять ТЗ v8 как базу (клиент его
подписал), но пункты из `profile-architecture` с обоснованием («Gemini Flash ломает таблицы в
.docx», «Gemini Flash на посты даёт мёртвый текст») перенести туда как антипаттерны.

## Делегирование проще, чем казалось

Проверено живьём на проде 2026-08-22:

```bash
hermes --profile docs chat -q 'задача'     # отработало, сессия 20260822_125519_aca5f4
```

Флаг `-p/--profile` штатный, профиль отвечает **из терминала**. У Геры `terminal` есть. То есть
базовый путь делегирования доступен **уже сегодня**, без kanban и без отдельных ботов. kanban
нужен для тяжёлого/асинхронного и для критик-цикла (`swarm`), но стартовать можно проще.

Этот способ уже описан в навыке `meta/profile-architecture` — то есть Гера про него знает и
всё равно делает сам. Подтверждает диагноз: проблема не в отсутствии механизма, а в отсутствии
принуждения.

авторского голоса» непроверяемо.
