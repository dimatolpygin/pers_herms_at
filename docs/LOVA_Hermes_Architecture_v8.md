# **4. Что делает каждый профиль**
## **Контент-бот**
- Автопостинг в Instagram, Telegram, VK, Pinterest (15+/мес)
- Генерация картинок (kie.ai) и дорисовка фона (FAL.ai)
- Обработка ссылок на товары: сбор фото/цен с Tilda
- Наложение логотипа и сайта на фото
- Написание текстов (Sonnet 5)
- Загрузка своих фото (S3)
- Промты для Midjourney / Syntx.ai
## **SEO-бот**
- Массовые правки meta-тегов через Tilda API
- Замена title/description/H1 на всех страницах
- Прописывание alt у картинок
- Сбор частотностей через Wordstat API
- Проверка индексации, robots.txt, sitemap
## **Документы-бот**
- Коммерческие предложения (.docx) с таблицами и фото
- Счета-оферты по образцу LOVA
- Закрывающие документы
- Расчёт налогов (УСН 6%, ИП без НДС)
- Форматирование: шрифты, логотип, таблицы
## **Литература-бот**
- Литературная обработка книг
- Корректура и вычитка
- Профессиональная редактура статей
- Сохранение авторского голоса Мики
- Убирает AI-штампы и канцелярит
## **Кодинг-бот**
- Vibe-кодинг: приложения, скрипты, расширения
- Tilda-автоматизация (Chrome Extension, Playwright)
- Веб-кодинг (HTML/CSS/JS)
- Backend-скрипты (Python)
- Сложное → Sonnet 5, обычное → Qwen Max
## **Стратег-бот**
- SEO-стратегии: семантическое ядро, кластеризация
- Маркетинговые стратегии: каналы, воронки
- JTBD-анализ: зачем клиент покупает
- Бренд-продвижение: позиционирование, tone of voice
- Конкурентный анализ: парсинг, сравнение
- Создание стратегических документов для других агентов

# **6. Критик-цикл (в каждом профиле)**
Каждый бот имеет встроенный цикл проверки качества в своём SOUL.md:

1. Основная модель генерирует результат
1. Критик (другая семья моделей) проверяет: стиль, факты, логику, ошибки
1. PASS → результат выдаётся Мике
1. FAIL → правки (максимум 2 попытки)
1. После 2 провалов → эскалация основному боту Гере

# **7. Ключевые риски и меры**
**Rate-limit 429:** Исключены модели с 429-проблемами (Qwen Flash). DeepSeek и Gemini стабильны.

**Стоимость Sonnet 5:** Sonnet используется только для творческих задач (текст, книга, аудит). Рутинная работа — на DeepSeek. Экономия ×3–5.

**Ошибки в цифрах (документы):** Критик Qwen Max пересчитывает суммы. Дополнительная сверка с образцами.

**Деградация контекста:** Каждый бот видит только свой контекст (~5K вместо 60K токенов). Нет «раздувания» общей памяти.

# **9. Настройка Telegram-ботов**
